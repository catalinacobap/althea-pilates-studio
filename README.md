# Estudio demo

Landing page responsive con identidad y contenido ficticios. Los enlaces son internos y no realizan reservas ni contactan negocios reales.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Los horarios se administran desde el arreglo `schedule` en `src/App.tsx`. Los enlaces principales se encuentran en las constantes al inicio del mismo archivo.
