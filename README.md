# Althea Pilates Studio

Landing page responsive para Althea Pilates Studio, Ciudad Quesada, Costa Rica.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Los horarios se administran desde el arreglo `schedule` en `src/App.tsx`. Los enlaces principales se encuentran en las constantes al inicio del mismo archivo.
